# Terrance leert letters

Cutout-style letter game for toddlers. One HTML file with everything baked in, hosted on GitHub Pages, installed on the home screen of an iPhone or Android tablet.

## Layout
- `src/rig.js` — character rig, sounds, animation defaults, player, voice (shared)
- `src/game.html`, `src/studio.html` — templates; `__RIG__` / `__ASSETS__` are filled by the build
- `assets/sounds/*.mp3` — sound effects (optional; synth fallback if missing)
- `assets/voice/nl/*.mp3` — voice clips, generated once by `tools/build-voice.js`
- `animations.json` — optional; export from the studio to override the built-in animations
- `config.json` — names, language, ElevenLabs voice settings
- `docs/` — build output (commit this, GitHub Pages serves it)

## First time
1. Node 18+. Edit `config.json` (kids' names, voice ID).
2. Put `ELEVENLABS_API_KEY=...` in a `.env` file (gitignored). `npm run voice` generates all phrases once (letters A–Z, names, numbers, praise), about 140 characters. Re-run after adding names; only missing clips are fetched. Uses the `eleven_v3` model with `language_code: nl`; single letters get a trailing period — that is what made the letters sound Dutch.
3. `npm run sfx` generates the sound effects (fart, bigfart, boing, thud, slip, whistle, splat, sneeze, ding, pop, spin) with the ElevenLabs sound-effects API into `assets/sounds/`. Prompts live in `tools/build-sfx.js`; `node tools/build-sfx.js fart` regenerates one.
4. `npm run build` → `docs/index.html` (game) and `docs/studio.html`.
5. `npm run serve` to test locally. Commit and push; GitHub Pages serves `main` / `/docs`.
6. `npm run voice-test <name=voiceId> ...` makes sample clips per voice in `voice-test/` (gitignored); open `voice-test/index.html` to compare them with the in-game pitch.

## On the phone / tablet
Open the Pages URL once, then "Add to Home Screen" (Safari share sheet on iPhone; Chrome menu on Android). It opens fullscreen and works offline after that since everything is inside the one file.

## Tuning animations
Open `docs/studio.html`, tweak, Download `animations.json`, put it in the repo root, `npm run build`.

## Keeping cost down
Voice is only generated by `build-voice.js`. The game never calls ElevenLabs unless you put a key in its ⚙ settings on the device (fallback for a name you haven't built yet).
